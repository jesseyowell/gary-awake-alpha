  `itemid` must be an item ID for an item in the project. These IDs are returned
  as the id field in other API calls.


  Note that they are NOT found in in URLs like
  `https://rollbar.com/myaccount/myproject/items/456/` – that is the "counter",
  which can be used in the following API call.
